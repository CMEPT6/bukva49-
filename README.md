## 📖 О проекте / Overview

**BUKVA-49** — это легковесная архитектура детерминированного рассуждения для автономных ИИ-агентов, экспертных систем и алгоритмического принятия решений.

Вместо непредсказуемых «чёрных ящиков» больших языковых моделей (LLM), которые склонны к галлюцинациям, ошибкам в арифметике и рекурсивным зацикливаниям, **BUKVA-49** разделяет процесс принятия решений на **49 дискретных когнитивно-вычислительных операторов**, организованных в каноническую матрицу 7 × 7:

* **100% детерминизм и воспроизводимость:** Любое решение даёт одинаковый результат независимо от фазы луны.
* **0 внешних зависимостей:** Чистый стандартный Python (`dataclasses`, `hashlib`, `json`, `random`, `re`).
* **Криптографическая верификация:** Каждое решение опечатывается SHA-256 контрольной подписью и полным аудиторским следом (audit trail).
* **Генетическая оптимизация пайплайнов:** Встроенный генетический алгоритм эволюционно находит кратчайшие формулы рассуждения.
* **Интерактивная кибернетическая студия:** Автономный HTML5-дашборд реального времени с визуализацией потоков состояний.

## ⚡ Быстрый старт / Quickstart

### 1. Использование в Python коде (5 строк)

```python
from bukva49 import EVOLVED, execute, make_tasks

# Генерируем задачу с коварными ловушками (неверифицированные дешёвые цены)
task = make_tasks(count=1, seed=297, regime="misleading")[0]

# Исполняем эволюционную формулу: Вѣди -> Есть -> Мыслите -> Йота -> Земля
state = execute(EVOLVED, task)

print(f"Выбран кандидат: {state.selected}")
print(f"Итоговый артефакт: {state.artifact}")
```

### 2. Автономный агент закупок (BukvaAgentPipeline)

```python
from bukva49 import BukvaAgentPipeline

pipeline = BukvaAgentPipeline()
quotes = [
    {"name": "Серый импорт", "price": 42000, "delivery": 12000, "source_verified": False},
    {"name": "Официал Дил", "price": 54000, "delivery": 2500, "source_verified": True},
    {"name": "Склад Экспресс", "price": 52000, "delivery": 6000, "source_verified": True},
]

state = pipeline.run("Закупка серверных комплектующих с обязательной верификацией", candidates=quotes)

print(f"Победитель: {state.selected_id}")
print(f"Итоговая стоимость: {state.best_score} руб.")
print(f"Печать SHA-256: {state.seal_hash}")
```

### 3. Запуск из командной строки (CLI)

```bash
# Вывести интерактивную матрицу 7 × 7 с расшифровкой кодов:
bukva49 matrix

# Запустить эволюционную формулу:
bukva49 run evolved

# Запустить генетический эксперимент (эволюция алгоритма):
bukva49 experiment --seed 297 --generations 50

# Запустить агента на пользовательском запросе:
bukva49 agent "Закупка памяти DDR5"
```

## 🏛️ Матрица 7 × 7 когнитивных операторов

Каждая буква древнеславянской матрицы сопоставлена со строгим математическим оператором конечного автомата:

| Ряд | Уровень архитектуры | Операторы и Опкоды |
|---|---|---|
| **Ряд 1** | **Бытие и Восприятие** *(Входной уровень)* | **Азъ** `INIT`, **Боги** `AXIOMS`, **Вѣди** `KNOW`, **Глаголи** `TRANSMIT`, **Добро** `VALUATE`, **Есть** `VERIFY`, **Есмь** `PRESENCE` |
| **Ряд 2** | **Структура и Связи** *(Топология данных)* | **Животъ** `LIFECYCLE`, **Ѕѣло** `BOUND`, **Земля** `GROUND`, **Иже** `MERGE`, **Ижеи** `ALIGN`, **Инить** `THREAD`, **Гервь** `ALERT` |
| **Ряд 3** | **Осмысление и Логика** *(Аналитический слой)* | **Како** `PATTERN`, **Людие** `NORMALIZE`, **Мыслите** `REASON`, **Нашъ** `INTERNAL`, **Онъ** `OBJECT`, **Покои** `FREEZE`, **Рѣци** `DECLARE` |
| **Ряд 4** | **Утверждение и Очищение** *(Фильтрация)* | **Слово** `EMIT`, **Твѣрдо** `ENFORCE`, **Укъ** `TRANSFORM`, **Оукъ** `EXPAND`, **Фѣртъ** `AUDIT`, **Хѣръ** `ROLLBACK`, **Отъ** `ISOLATE` |
| **Ряд 5** | **Разделение и Детализация** *(Селекция)* | **Ци** `TARGET`, **Червль** `FORMAT`, **Ша** `INDEX`, **Ща** `COMPRESS`, **Еръ** `SOLIDIFY`, **Еры** `AGGREGATE`, **Ерь** `RELAX` |
| **Ряд 6** | **Эволюция и Трансформация** *(Оптимизация)* | **Ять** `CROSS`, **Юнь** `MUTATE`, **Арь** `REFINE`, **Эдо** `PROBE`, **Омъ** `HARMONIZE`, **Енъ** `SEED`, **Одь** `WEIGH` |
| **Ряд 7** | **Синтез и Завершение** *(Интегральный уровень)* | **Йота** `EXTRACT_KEY`, **Ота** `DIFF`, **Кси** `COMPARE`, **Пси** `SPIRIT`, **Фита** `SYNTHESIZE`, **Ижица** `FALLBACK`, **Ижа** `SEAL` |

## 🧬 Открытие генетического алгоритма (Формула 0.990)

В ходе 50 поколений генетической селекции среди 1218 уникальных программ:
1. Базовая формула человека **`297` (`Вѣди → Фита → Земля`)** показала **0.0% точности** на задачах с ловушками, так как не содержала фильтра верификации.
2. Классическая формула **`FULL` (`Вѣди → Есть → Мыслите → Кси → Фита → Земля`)** достигла 100% точности, но тратила 6 шагов.
3. Генетический поиск выявил оптимальную формулу **`EVOLVED` (`Вѣди → Есть → Мыслите → Йота → Земля`)**:
   * Оператор **«Йота»** (буква №43, опкод `EXTRACT_KEY`) объединяет сортировку (`Кси`) и выборку (`Фита`) в единую атомарную операцию.
   * Результат: **100.0% точность**, сокращение вычислительных шагов на 17%, рекордный скор **0.990**.
