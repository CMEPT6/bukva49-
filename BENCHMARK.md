# Методология и честный бенчмарк BUKVA-49 (BENCHMARK.md)

В данном документе приведено строгое описание методологии тестирования, сравнительный анализ со стандартным Python и анализ роли операторов матрицы.

---

## 1. Сравнение с эталонной функцией (Ground Truth Control)

Формула **EVOLVED** (`Вѣди → Есть → Мыслите → Йота → Земля`) сравнивается с эквивалентной 3-строчной функцией на чистом Python:

```python
def direct_reference(task: Task) -> str:
    valid = [o for o in task.offers if o.source_verified]
    if not valid:
        return task.offers[0].id
    return min(valid, key=lambda o: (o.price + o.delivery, o.id)).id
```

### Результаты (тест на 4000 случайных задачах):
* **Совпадение решений:** 4000 / 4000 (100.0%)
* **Время чистой функции Python:** ~6.5 мс (~1.6 мкс / задача)
* **Время FSM-интерпретатора BUKVA-49:** ~22.0 мс (~5.5 мкс / задача)

### Вывод:
Интерпретатор FSM приблизительно в **3.5–4 раза медленнее**, чем инлайн-код на Python. Это ожидаемо: FSM поддерживает структуру состояния (`State`), валидирует переходы, строит трассировку и формирует артефакт.  
**Ценность BUKVA-49 заключается не в скорости вычислений, а в формализации шагов принятия решения, пошаговом аудите и криптографической неизменяемости.**

## 2. Статус 49 операторов матрицы

Матрица 7 × 7 операторов по результатам мутационного анализа распределяется следующим образом:

| Категория | Количество | Описание | Примеры |
|---|---|---|---|
| **Влияющие на выбор (Decision Drivers)** | **12** | Непосредственно трансформируют данные, фильтруют по условиям, считают формулу или берут минимум | `Вѣди`, `Добро`, `Есть`, `Животъ`, `Ѕѣло`, `Мыслите`, `Отъ`, `Ща`, `Еръ`, `Йота`, `Кси`, `Фита` (+ `Ижица`) |
| **Аудит и контроль (Audit & Guardrails)** | **20** | Записывают аудиторский след, проверяют контракты, фиксируют инварианты и вычисляют криптографическую печать | `Азъ`, `Боги`, `Глаголи`, `Есмь`, `Земля`, `Иже`, `Ижеи`, `Инить`, `Гервь`, `Како`, `Людие`, `Нашъ`, `Онъ`, `Покои`, `Рѣци`, `Слово`, `Твѣрдо`, `Фѣртъ`, `Пси`, `Ижа` |
| **Зарезервированные (Reserved Stubs)** | **17** | Зарезервированы под расширенные профили (многокритериальная оптимизация, теория игр, квантили) | `Укъ`, `Оукъ`, `Хѣръ`, `Ци`, `Червль`, `Ша`, `Еры`, `Ерь`, `Ять`, `Юнь`, `Арь`, `Эдо`, `Омъ`, `Енъ`, `Одь`, `Ота` |

## 3. Тестирование агента (BukvaAgentPipeline)

Агент протестирован на 100 синтетических задачах (по 25 на каждое из 4 семейств):

| Семейство | Описание задачи | Точность | Причина отсева ошибок |
|---|---|---|---|
| **`offer`** | Отбор поставщиков с дедлайном и подтверждением | **25 / 25 (100%)** | Отсечение невалидных сроков и неподтверждённых офферов |
| **`inventory`** | Складской пересчёт с отменами и резервами | **25 / 25 (100%)** | Игнорирование отменённых проводок и резервов |
| **`rating`** | Шахматный турнир со стрик-бонусом | **25 / 25 (100%)** | Точный расчёт дельт и серий побед |
| **`source`** | Выбор актуальной версии документа по дате | **25 / 25 (100%)** | Игнорирование черновиков независимо от новизны даты |

## 4. Криптографическая защита от подделки (SHA-256 Context Sealing)

Печать `Ижа` рассчитывается от полного канонического JSON-представления:
* Входные предложения (`evidence`)
* Начальные условия (`initial_value`)
* Выбранный результат (`selected_result`)
* Итоговая метрика (`best_score`)
* Длина и состав аудиторского следа

При изменении хотя бы 1 цифры или 1 рубля во входных данных хеш полностью меняется, гарантируя, что решение принималось именно по предъявленным документам.
