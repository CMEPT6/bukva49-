# Разметка настоящих лотов: короткая инструкция

Цель: 20-30 лотов, по которым эталонный ответ определён правилами лота и Правилами закупок, а не мнением модели или наших скриптов.

## Что брать
- Публичные лоты с портала закупок: объявление, техническая спецификация, поданные предложения, итоговый протокол.
- Разные ситуации: есть явный победитель; самый дешёвый отклонён; есть срок поставки; есть предельная сумма; есть демпинг; допустимого победителя нет. Не набирайте только «простые» лоты.
- Запишите способ закупки и редакцию Правил на дату лота (пороги демпинга зависят от способа и вида предмета).

## Как размечать
1. Скопируйте `lot_template.json`, по одному объекту на лот.
2. `text` и `offers_text` - вставляйте дословно, без исправлений, как их увидит модель.
3. `gold.constraints` - только то, что есть в тексте лота. Нет в тексте - `null`.
4. `gold.quotes` - дословная цитата из `text` для каждого непустого ограничения.
5. `gold.candidates` - предложения по полям. Цены приводите к тем условиям, по которым лот велит сравнивать (с НДС или без).
6. `gold.winner_id` - кого должна выбрать система по условиям лота; `null`, если допустимого нет.
7. Разметку делают двое независимо. Расхождения обсуждают и фиксируют, в чём была разница.

## Чего не делать
- Не берите эталон из ответа модели и не просите модель размечать лоты, которые потом ею проверяются.
- Не подменяйте правила лота правилами «из памяти». Порог демпинга берите из текста лота и действующих Правил.
- Итоговый протокол комиссии - контрольная точка, не истина: если ваша разметка с ним расходится, разберитесь, кто прав, и запишите.
- Не удаляйте «неудобные» лоты, где система ошибается: именно они нужны.

## Проверка
```bash
python eval_harness.py --lots ваш_файл.json --check-gold
```
Команда ловит арифметические ошибки и цитаты, которых нет в тексте. Независимую проверку человеком она не заменяет.

## Первый запуск
Начните с 3-5 лотов, чтобы отладить шаблон, затем разметьте остальные. Прогон на модели и отчёт: с числом лотов, доверительными интервалами и долей ложных отказов.
